# Vue3 排序算法可视化

日期：2026-10-26  
状态：已评审（对话确认），待实现

## 1. 目标

做一个 Vue3 单页演示：用户指定柱子数量并生成，柱子高度先按容器高度从矮到高算好，再随机打乱；提供五种常用排序按钮，每一步交换/写入都带动画；排序结束后（或中途停止时）展示移动次数与耗时。

## 2. 已确认决策

| 项 | 选择 |
|----|------|
| 技术栈 | Vite + Vue3 + TypeScript |
| 架构 | 单页直写 + 步骤队列（方案 1） |
| 算法 | 冒泡、选择、插入、快速、归并 |
| 移动次数 | 只计交换 / 写入位置（`swap` / `write`） |
| 动画 | 每步交换/写入播一帧，逐步播放 |
| 打断 | 排序中可「停止」或「重新打乱」 |
| 数量 | 可手动填写，点「生成柱子」生效（非固定 200） |

## 3. 界面

从上到下：

1. **控制区**
   - 数量输入（默认建议 `100`，合法范围 `2～500`）
   - 「生成柱子」「停止」「重新打乱」
   - 五个排序按钮：冒泡 / 选择 / 插入 / 快速 / 归并
2. **柱状图区**：等宽蓝色细柱，横向铺满可用宽度，高度用 px
3. **统计区**：移动次数、耗时（秒，保留 2 位）；注明耗时「含动画」。状态文案：未开始 / 进行中 / 已完成 / 已停止

交互约束：

- 未生成柱子前：排序按钮禁用
- 排序进行中：五个排序按钮禁用；停止、打乱、生成可用
- 「生成柱子」或「重新打乱」若在排序中：先 abort，再执行

## 4. 柱子生成

点「生成柱子」时：

1. 校验 `n ∈ [2, 500]`，非法则提示，不生成
2. 读取柱状图容器当前可用高度
3. 生成 `n` 个严格递增高度：`h[i] = minH + i * step`（`minH` 约 4px，最高接近容器高度）
4. Fisher–Yates 打乱后写入 `bars` 数组 → 画面高低混乱
5. 清空统计；若正在排序则先停止

「重新打乱」：不改 `n`、不改高度集合，只对当前数组再 shuffle；清空统计。

柱子数据建议形如：`{ id: number, height: number }`，`:key="id"`，交换时改 height，CSS `transition` 过渡高度。

柱宽 ≈ 容器宽度 / n（可留小 gap）。

## 5. 算法与步骤队列

`src/sorts.ts` 为纯函数：对数组**副本**跑算法，产出步骤列表，不直接改 UI。

步骤类型：

- `swap(i, j)`：交换下标 i、j（冒泡 / 选择 / 插入 / 快排）
- `write(i, value)`：写入下标 i（归并写回、插入移位等）

每种算法一个入口，例如 `bubbleSortSteps(heights: number[]): Step[]`。

播放器（在 `App.vue`）：

1. 点排序 → 生成完整步骤队列 → `running = true`，`t0 = performance.now()`
2. 循环：应用一步 → `moves++` → `await delay(~40ms)`；检查 `abort`
3. 正常结束：`elapsed = (now - t0) / 1000`，状态「已完成」
4. 停止：跳出循环，保留当前柱子；状态「已停止」，仍显示当前 moves 与已耗时

## 8. 自测清单

- [ ] 输入合法数量 → 生成 → 柱子数量正确、高度混乱
- [ ] 非法数量有提示且不生成
- [ ] 五种排序均可从乱序排到有序，动画可见
- [ ] 结束后显示移动次数与含动画耗时
- [ ] 中途停止：柱子停在中间态，统计为已停止
- [ ] 停止后再点排序可继续对当前数组排序
- [ ] 排序中点「重新打乱」或「生成」会中断并刷新

## 9. 实现备注

- 耗时含 `delay`，反映演示用时，不是纯 CPU 排序时间
- 快排 / 归并对较大 `n` 步骤可能很多，属预期；用户可用停止打断
- 人类可读优先：主路径留在 `App.vue` + `sorts.ts`
